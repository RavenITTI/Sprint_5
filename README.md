# Проект Stellar Burgers: Автоматизация UI-тестов
Этот проект содержит автотесты для веб-приложения **Stellar Burgers**. 
## Структура проекта
- `tests/` — директория с тестами, разделенными по функциональности.
- `conftest.py` — конфигурационный файл с фикстурами для инициализации браузера и подготовки данных.
- `locators.py` — описание всех используемых элементов страниц.
- `helpers.py` — вспомогательные функции для генерации тестовых данных.

В рамках проекта реализованы следующие автотесты:

### 1. Регистрация пользователя (`test_registration.py`)
* Успешная регистрация при вводе валидных данных.
* Ошибка при регистрации с некорректным паролем (менее 6 символов).

### 2. Вход в систему (`test_login.py`)
* Вход по кнопке «Войти в аккаунт» на главной странице.
* Вход через кнопку «Личный кабинет».
* Вход через форму регистрации.
* Вход через форму восстановления пароля.

### 3. Личный кабинет (`test_personal_cabinet.py`)
* Переход по клику на «Личный кабинет».
* Переход из личного кабинета в конструктор (по клику на «Конструктор» или логотип Stellar Burgers).
* Выход из аккаунта.

### 4. Конструктор (`test_constructor.py`)
* Проверка работы переходов к разделам: «Булки», «Соусы», «Начинки».

Тесты написаны на языке **Python** с использованием библиотеки **Selenium** и фреймворка **Pytest**.
